# tournament-bracket-engine

Бэкенд-сервис для генерации и ведения турнирных сеток Single Elimination. Написан на FastAPI, обновляет счет и продвигает победителей в реальном времени через WebSockets.

## Что внутри

- Построение сетки на выбывание с учетом посева участников (сильные игроки разводятся по разным веткам).
- Автоматический перевод победителя в следующий раунд при фиксации счета матча.
- Рассылка обновлений сетки подключенным клиентам по WebSocket.
- Готовый Dockerfile и docker-compose для запуска в контейнере.

## Запуск

Локально:

```bash
pip install -r requirements.txt
python main.py
```

Через Docker:

```bash
docker-compose up --build
```

Документация эндпоинтов (Swagger): `http://127.0.0.1:8000/docs`.
