# tournament-bracket-engine

Движок проведения турниров и генерации турнирных сеток на FastAPI и WebSockets.

## Возможности
- Автоматическая генерация турнирных сеток Single Elimination по номерам посева участников.
- Обработка продвижения победителей по раундам при обновлении счета.
- WebSocket-канал для трансляции изменений счета в реальном времени.
- Контейнеризация через Docker и Docker Compose.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Интерактивная документация Swagger доступна по адресу `http://127.0.0.1:8000/docs`.
